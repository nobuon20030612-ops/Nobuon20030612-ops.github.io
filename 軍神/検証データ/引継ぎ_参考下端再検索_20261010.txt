【引継ぎ｜信長の野望Online 軍神 能力推定・参考下端再検索 2026-10-10】

■受領元と目的
軍神データ(2).csv（114柱・18項目）を唯一の正本とし、変更していない。
研究用の「軍神_三貴神3回_奉納物なし_最終整合_114体_統一参考値.csv」から、114柱の中央値と参考下端の差のみを抽出した。
ただし固定Lv軍神5柱［No.7・11・15・19・94］へ通常育成の下端を適用していない。
研究用参考値の下端はゲーム実測値・保証付き下限・統計的信頼区間ではない。

■今回の実行結果
通常育成109柱×11能力のうち、中央値から1低い参考下端が579項目。
生命力・気合は変動なし。残る9能力で215コスト構成×TOP500を既存の profile_top500() により再生成し、現行DBと比較。
能力別の215構成CSVは1935行、おすすめTOP500比較CSVは11行。
同点の組合せが入れ替わる場合も「首位変更」に含むので、首位得点の変化と分けて解釈すること。

■使用方法（既存の軍神フォルダへ同名パスで上書き／追加）
python 更新検索データ.py --lower-audit
  研究用参考下端による再計算。正本CSV、元倍率、現行検索DB、サイト表示は変更しない。
python 更新検索データ.py --stress
  旧来の「通常育成軍神の各九光能力±1」の検証、根拠SHA256も更新。
python 更新検索データ.py --verify
  従来の全215構成・検索DB・実測照合に加えて、参考下端検証・順位感度検証の元データ／結果ファイルが古くないかをチェック。
CSV/倍率/検索DBを更新したら、--stress と --lower-audit の両方を再実行して検証元を更新すること。
